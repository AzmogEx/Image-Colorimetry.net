# Image-Colorimetry.net

Ce projet est un logiciel simple développé en .NET permettant de modifier la colorimétrie des images et d'afficher les fromages typiques de chaque région de France. L'objectif est de fournir une interface simple pour ajuster les couleurs des images tout en découvrant des spécialités locales.

## Fonctionnalités

* Modification des couleurs d'images (luminosité, contraste, saturation, etc.)
* Affichage des fromages par région de France
* Interface utilisateur intuitive et facile à utiliser
* Exploration des régions de France et leurs spécialités fromagères

## Technologies utilisées

* .NET
* WPF (Windows Presentation Foundation) pour l'interface utilisateur
* Base de données locale pour stocker les informations sur les fromages

## Installation

1. Cloner le dépôt :

   ```bash
   git clone https://github.com/AzmogEx/Image-Colorimetry.net.git
   ```

2. Ouvrir le projet avec Visual Studio
3. Restaurer les packages NuGet
4. Lancer l'application depuis Visual Studio

## Utilisation

1. Importer une image pour commencer à la modifier
2. Utiliser les outils de modification de colorimétrie pour ajuster l'image selon vos préférences
3. Sélectionner une région de France pour afficher les fromages typiques associés à cette région
